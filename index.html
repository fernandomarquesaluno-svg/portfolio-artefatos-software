Os três processos

DSR

Verifica se um artefato resolve um problema de pesquisa.

Critérios → aplicação → evidências → refinamento

SBC — SBSeg / SBRC

Examina os artefatos associados a um artigo conforme o evento.

Submissão → revisão → reprodução → selos

MA-MPS / Softex

Avalia processos organizacionais por evidências e entrevistas.

Preparação → avaliação inicial → final → resultado

Prompts utilizados

Prompt 1 · Avaliação analítica
Atue como um avaliador do comitê de artefatos do evento SBRC 2026. Com base exclusivamente nas instruções oficiais de avaliação de artefatos do SBRC 2026 e na documentação disponível no repositório (https://github.com/rafaeloj/sbrc2026), faça uma avaliação analítica do artefato "Selection Agent (K-Agent)". Indique se os selos F (Funcional) e R (Reprodutível) devem ser atribuídos. Para cada selo, exija o veredito final, as evidências encontradas na documentação que sustentam a sua decisão e aponte quaisquer falhas ou lacunas identificadas.
Prompt 2 · Reavaliação após logs
Agora, reavalie os selos F e R com base nos resultados da execução prática do artefato. Ambiente: Ubuntu 22.04 LTS, Python 3.10, PyTorch 2.7.1, CPU 8 vCPUs, 16 GB RAM. Teste 1 (Método random): Comando: cd selection-agent && flwr run . local-simulation (selection-method='random', num-server-rounds=1). Resultado: [SUCCESS] Simulation finished. Modelo salvo em models/20260315_random_final_model_.pt. Teste 2 (Método K-Agent): Comando: selection-method='k-agent', num-server-rounds=50. Resultado: Tentativa de conexão com Ollama (modelo qwen3:0.6b) gerou erro ConnectionRefusedError em http://localhost:11434. A execução falhou e foi abortada. Com base nessas evidências de execução, confirme ou revise os seus julgamentos anteriores para os selos F e R, justificando a decisão.

Prompts disponibilizados em versão reconstruída; deve-se verificar se as instruções oficiais completas foram enviadas a cada modelo.
