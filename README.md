# artefatos.lab — Portfólio acadêmico

Site de Fernando Henrique de Souza Marques sobre avaliação de artefatos de software, com as Atividades 6, 7 e 8.

## Acesso ao site

Depois de habilitar GitHub Pages em **Settings → Pages → Deploy from a branch → main → /(root)**, a página deverá ficar disponível em:

https://fernandomarquesaluno-svg.github.io/portfolio-artefatos-software/

**A URL só será válida depois do deploy ser ativado e concluído.**

## Conteúdo

- **Atividade 6:** comparação documental entre DSR, avaliação de artefatos em eventos da SBC e MA-MPS.
- **Atividade 7:** avaliação do Selection Agent (K-Agent) com GPT-6, Claude 3.5 Sonnet e Gemini 1.5 Pro; duas fases, logs, prompts e comparação com o SBRC 2026.
- **Atividade 8:** protocolo de oito configurações experimentais de LLMs para analisar sensibilidade a versões e esforço; execuções controladas ainda pendentes.

## Arquivos

O `index.html` é autônomo: estilos e JavaScript estão incorporados ao próprio documento. Não há etapa de instalação, build ou servidor próprio.
