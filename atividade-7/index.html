01 / Protocolo

Do README ao experimento

O mesmo artefato e as mesmas diretrizes do SBRC foram utilizados para comparar os pareceres. A execução prática foi realizada no ambiente descrito pelo aluno; não se tratou de revisão oficial do CTA.

ETAPA 01

Revisão documental

Leitura das instruções do CTA, do README e dos materiais do repositório. Cada modelo registra sua interpretação de F e R.

ETAPA 02

Execução e logs

O relato do teste com seleção aleatória e da tentativa inicial do K-Agent foi usado para revisar as recomendações.

ETAPA 03

Triangulação

Comparação dos pareceres, das evidências de execução e dos selos oficiais do evento, com uma auditoria posterior registrada separadamente.

Controle importante: uma simulação random concluída não comprova, isoladamente, o ciclo de seleção por LLM. A recusa de conexão com Ollama também não comprova falha do algoritmo.

05 / Síntese

A discordância é um resultado.

Não basta perguntar à LLM se o artefato merece um selo. É preciso registrar versões, executar procedimentos, auditar os logs e verificar se o parecer corresponde ao código e ao critério oficial.
